## 🎯 Activité pratique / Remise

**TP1** : en équipe, corrigez un premier bogue simple identifié dans le projet du cours, via une
vraie Pull Request sur GitHub :

- Une description claire du bogue corrigé et de la correction apportée.
- Une capture d'écran (ou un lien) montrant que les tests passent.
- Au moins une revue de code croisée entre équipes avant la fusion.

Cette activité met immédiatement en pratique le cycle complet vu cette semaine : lecture de code,
création d'une branche, commit, push, ouverture d'une Pull Request, et revue de code.
