## 🎯 Objectifs d'apprentissage de la semaine

À la fin de cette semaine, vous devriez être capable de :

- Expliquer ce qu'est la maintenance logicielle et nommer ses 4 types (ISO/IEC 14764).
- Expliquer pourquoi la maintenance représente la majorité du coût de vie d'un logiciel.
- Cloner, configurer et démarrer localement un projet existant.
- Expliquer ce qu'est une API REST.
- Utiliser les commandes Git de base (`clone`, `checkout`, `add`, `commit`, `push`, `pull`) pour
  gérer votre propre copie du code.
- Repérer, à l'œil, qu'un bout de code « sent mauvais » — sans nécessairement savoir encore le
  nommer formellement.
